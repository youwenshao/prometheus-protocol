# The Prometheus Protocol

> *Bring fire, not burns.*

This folder teaches an AI coding agent how to work with you: set up your computer, keep work from getting stranded, and grow into a durable workflow. You do not need to read the rest of the files.

You do not need git, a GitHub account, or a terminal to start.

## Start here

1. Install [Cursor](https://cursor.com) and open it.
2. Open the Agent chat. Any folder is fine — including a blank window.
3. Copy the block below, paste it, send.

```
Initialize the Prometheus Protocol from https://github.com/youwenshao/prometheus-protocol

I am new. Fetch that repo onto this computer (clone or download the ZIP — you choose). Read AGENTS.md and begin START.md. Ask before you install anything, create accounts, or put anything on the internet.
```

That is the whole start. The agent will get the protocol, then set up what it needs to keep working after this chat. It will ask before it installs anything or creates accounts. If something needs you to click in a browser (signing in, creating an account), it will stop and wait.

When it is done, you will have a computer the agent can keep working on, a way to continue in a new chat, and a way to undo this protocol. Then it will ask what you actually wanted to build.

## If the paste cannot fetch the repo

On this GitHub page, click **Code → Download ZIP**, unzip it, then in Cursor: **File → Open Folder…** and choose that folder. Paste the same prompt again.

## Later

- New chats inherit the protocol after the first session. You do not need this folder open.
- To remove everything this protocol added, paste: `Uninstall the Prometheus Protocol. Read UNINSTALL.md.` Or open [UNINSTALL.md](UNINSTALL.md).
