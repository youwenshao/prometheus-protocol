# The Prometheus Protocol

> *Bring fire, not burns.*

This folder teaches an AI coding agent how to work with you: set up your computer, keep work from getting stranded, and grow into a durable workflow. You do not need to read the rest of the files.

You do not need git, a GitHub account, or a terminal to start.

## Do this

1. Install [Cursor](https://cursor.com) and open it.
2. Get this folder onto your computer. On the GitHub page, click **Code → Download ZIP**, then unzip it. (If someone already handed you this folder, skip this step.)
3. In Cursor: **File → Open Folder…** and choose the unzipped folder (the one that contains this `README.md`).
4. Open the chat (the Agent panel).
5. Paste this, then send:

```
You are onboarding me. Read AGENTS.md and begin START.md.
```

That is the whole start. The agent will ask before it installs anything or creates accounts. If something needs you to click in a browser (signing in, creating an account), it will stop and wait.

When it is done, you will have a computer the agent can keep working on, a way to continue in a new chat, and a way to undo this protocol. Then it will ask what you actually wanted to build.

## If you already have git

Clone this repository and open that folder in Cursor instead of downloading a ZIP. Then paste the same sentence.

## Later

- New chats inherit the protocol after the first session. You do not need to open this folder every time.
- To remove everything this protocol added, open chat and say: `Uninstall the Prometheus Protocol. Read UNINSTALL.md.` Or open [UNINSTALL.md](UNINSTALL.md) and follow it.
