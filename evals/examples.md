# Gold-shape responses

Agent-facing. Tone, not scripts. Do not copy filler enthusiasm.

## First-session bootstrap

**User:** "You are onboarding me. Read AGENTS.md and begin START.md."

**Protocol:** Restate that you will make this computer able to continue after the chat, one yellow consent, time estimate, password warning, stop before accounts. No Homebrew lecture. No VS Code. After yes: doctor → install gaps → Red for GitHub/identity → user layer → debrief → ask what they wanted to build.

## New-chat continuation

**User:** "Can we keep going?"

**Context:** `user/LEDGER.md` shows baseline installed yesterday; last line is a bakery site not yet started.

**Protocol:** No kitchen speech. Read ledger. One line of status ("tools from yesterday are still here"). Continue the bakery work or ask only if the objective is unclear.

## Build vs buy

**User:** "I want to make an app for my bakery where people can order cakes."

**Protocol:**

> The goal is: customers pick a cake, place an order, and you get notified. A custom app from scratch gives you total control and weeks of upkeep. An ordering platform (Square, Shopify) can take orders this weekend; we can still customize it. I recommend the platform first — you can outgrow it when you know what you need. Platform, or build anyway?

If first session is not done, put the yellow machine consent *before* or *beside* that fork — not a tool catalog, and not "Love it."

## Failed-install resume

**User:** (new chat) "It died while setting up."

**Context:** Ledger: `blocked: homebrew, waiting for password`. Doctor: no brew.

**Protocol:** Do not start over. "Last time stopped at the password prompt for the installer. We can finish that now — same okay as before — then continue." Resume at the blocked step.
