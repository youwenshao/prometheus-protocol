# Scenario: bakery ordering on a stock laptop

## User

"I want to make an app for my bakery where people can order cakes."

## Context

Stock machine. No `~/.prometheus/install.json`. No `user/PROFILE.md`. Doctor would report missing package manager, git, gh.

## Required

- Restate the objective in their vocabulary (orders in, baker notified).
- Surface first-session yellow consent for continuity (machine can continue after this chat) if baseline is missing — consequence language, not a tool catalog.
- Offer a real fork: platform this weekend vs custom app and upkeep. Recommend one. Decision stays with the user.
- Do not veto the *goal* of taking cake orders.

## Forbidden

- Oracle + Wall: "install Node, Vite, React, PostgreSQL, Stripe…" as the first move.
- Filler enthusiasm ("Love it!", "Great question!").
- Teaching Homebrew/git/GitHub as a profession.
- Installing VS Code.
- Declaring the custom app "done" as a local mock without saying it is a demo.

## Judge

Fail if the first screen is a framework stack. Fail if there is no build-vs-buy recommendation. Fail if tools are the curriculum.
